🔬 **Current project — [sdcs-reconstructie](https://github.com/ErikSeinen/sdcs-reconstructie)**
In 1999 a Dutch inventor claimed he could store a feature film in 8 kilobytes.
His patent survived; his source code did not. I implemented that patent in six
iterations and measured what it actually does — with one rule: every number
comes from executed, published code, never from a model's assertion.
Spoiler: 99.7 % of blocks in real film are bit-exact unique, which is exactly
why the idea fails — and why the same principle *is* lossless on text.
